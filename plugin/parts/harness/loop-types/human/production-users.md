# Users in production

## Loop

The signal comes from users in production:

- feedback
- support tickets
- A/B tests
- dogfooding

A human operator turns these signals into acceptance criteria. The agent gets the criteria as a spec and a test.

## Getting a good signal

- Take the problem from the user, not the solution.
- Tie every complaint to a reproducible scenario.

## Notes

- The source note calls this the slowest and noisiest signal of its loops, but the only one that shows whether the work has real value. The note gives no data for this claim.

## When and how long

Production; days to weeks.
