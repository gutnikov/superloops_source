# Debugger and REPL

## Loop

The agent sets a breakpoint or opens a REPL and checks its hypothesis against real values instead of guessing.

## Set up

- Use a non-interactive mode, such as scripted pdb or `node --inspect`.

The research names only these two modes. It gives no commands, harness steps or other runtimes, so you have to work out the setup for your project yourself.
