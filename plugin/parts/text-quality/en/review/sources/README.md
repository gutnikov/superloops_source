# Sources

The reviewer opens these files when it is unsure whether a passage fits a pattern, and always
before it gives severity 1. The catalogue (`../error-patterns.md`) links each code to them.
Every file here is public domain or under an open licence; copyrighted books are cited by
name and chapter only, never copied.

| Folder | What | Licence |
|---|---|---|
| `plain/guidelines/` | US Federal Plain Language Guidelines, as published on plainlanguage.gov (source repo `GSA/plainlanguage.gov`, archived), one file per guideline, grouped by section: `audience`, `organize`, `concise`, `conversational`, `words`, `design`, `web`, `test` | Public domain in the US; CC0 1.0 worldwide |
| `plain/examples/` | Before-and-after examples from plainlanguage.gov | Same |
| `govuk/` | GOV.UK "Writing to GOV.UK standards": the writing guidelines (clear language, structure, titles, summaries, links, tone, user needs), the A to Z style guide (with "Words to avoid") and the technical A to Z. Fetched 2026-11-04 from guidance.publishing.service.gov.uk | Contains public sector information licensed under the Open Government Licence v3.0 |
| `strunk/` | William Strunk Jr., *The Elements of Style* (1918/1920 edition): section II, Elementary Rules of Usage (rules 1–7), section III, Elementary Principles of Composition (rules 8–18), and section V, Words and Expressions Commonly Misused. Text from Project Gutenberg eBook #37134, Gutenberg header and licence removed | Public domain |

Cited, not copied (the catalogue names the book and chapter; models know these well):

- George Orwell, "Politics and the English Language" (1946): the six rules
- Joseph M. Williams, *Style: Lessons in Clarity and Grace*: characters as subjects, actions as verbs; old before new
- Steven Pinker, *The Sense of Style*: the curse of knowledge, zombie nouns, classic style
- Barbara Minto, *The Pyramid Principle*: answer first
- William Zinsser, *On Writing Well*: clutter
- H. W. Fowler, *A Dictionary of Modern English Usage*: elegant variation, popularized technicalities
- Darrell Huff, *How to Lie with Statistics*: figures that are not there, semi-attached figures
